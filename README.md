## 📖 Descripción del Proyecto

Este repositorio contiene la resolución integral de los **20 ejercicios** correspondientes a la Relación I del módulo DWES. El objetivo principal de estas prácticas es asentar las bases lógicas y sintácticas de la programación del lado del servidor utilizando **PHP**. 

El proyecto abarca desde el manejo de tipos de datos, incrustación de PHP en HTML y uso de variables superglobales, hasta la implementación de algoritmia matemática, estructuras de control de flujo y manipulación compleja de arrays. Todo el código ha sido desarrollado priorizando la limpieza, la refactorización segura y la correcta separación visual.

---

## 📂 Estructura del Repositorio y Ejercicios

La entrega está estructurada de forma secuencial. A continuación, se detalla el contenido y las competencias trabajadas en los distintos bloques del proyecto:

### 1️⃣ Fundamentos y Entorno de Servidor (Ejercicios 1 - 3)
- ✔️️ **Salida y Tipado:** Impresión de texto y formateo HTML utilizando `echo`, combinados con funciones de depuración como `var_dump()` y salidas formateadas con `printf()` para la exploración de datos escalares.
- ✔️ **Metadatos:** Extracción de configuración del servidor local mediante `phpversion()` y manipulación temporal con `date()`.
- ✔️ **Superglobales:** Volcado y recorrido iterativo del array `$_SERVER` para extraer información clave de la arquitectura HTTP y del entorno de ejecución.

### 2️⃣ Estructuras de Datos y POO (Ejercicios 4 - 6)
- ✔️ **Arrays Constantes:** Declaración de arrays indexados y asociativos para almacenar series de datos (días de la semana y temperaturas).
- ✔️ **Integración Frontend:** Procesamiento de datos mediante `for` y `foreach` para su volcado dinámico en estructuras HTML semánticas (listas `<ul>`, `<ol>` y tablas `<table>`).
- ✔️ **POO Básica:** Definición arquitectónica de clases (ej. clase `fruta`), con encapsulamiento de atributos, constructores, getters, setters e instanciación de objetos en memoria.

### 3️⃣ Lógica y Control de Flujo (Ejercicios 7 - 12)
- ✔️ **Bifurcaciones Complejas:** Empleo de `if`, `elseif`, `else` y operadores booleanos para calcular notas ponderadas y clasificar figuras geométricas (triángulos).
- ✔️ **Refactorización Matemática:** Implementación de un algoritmo para resolver ecuaciones de segundo grado, validando y aislando divisiones por cero o escenarios de coeficientes nulos.
- ✔️ **Bifurcación Múltiple:** Clasificación de rangos numéricos utilizando la sentencia `switch` con manejo de casos por defecto y validación de tipos.

### 4️⃣ Algoritmia, Bucles y Conversión (Ejercicios 13 - 20)
- ✔️ **Acumuladores y Contadores:** Diseño de iteraciones (`for`, `while`, `do-while`) aplicadas al cálculo de factoriales y sumatorios naturales.
- ✔️ **Optimización de Procesos:** Implementación de interrupciones lógicas (`break`) para optimizar el cálculo de números primos y el listado de divisores.
- ✔️ **Algoritmo de Euclides:** Resolución de divisiones naturales y obtención del Máximo Común Divisor (MCD) basándose en métodos de restas sucesivas.
- ✔️ **Bases Numéricas:** Desarrollo de un conversor universal (Decimal a Binario, Octal y Hexadecimal) gestionando arrays de resultados, `array_push()`, e inversión de índices para la concatenación final de cadenas.
